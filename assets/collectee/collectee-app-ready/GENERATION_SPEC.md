# Collectee asset generation specification

## Shared direction

- Use the supplied Collectee flow boards only as references for polish, lighting, density, and mobile-card framing.
- Produce original non-infringing prototype concepts; do not copy recognizable publisher characters, costumes, logos, faces, or compositions.
- One PNG contains exactly one hero/skin, item, or weapon.
- Hero/skin cards use a portrait 4:5 composition, centered waist-up or chest-up.
- Item/weapon cards use a square 1:1 composition with one fully visible object.
- No text, logos, watermarks, split panels, collages, companion figures, or extra display objects.
- Visual system: premium game splash art; dark backgrounds; violet, cyan, magenta, blue, gold, or ember accents according to metadata.
